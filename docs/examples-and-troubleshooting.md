The `ftui`/`ftht` directory names describe demo origins. These examples use the facade, so pass `--web` explicitly to view an HTTP interface. Example programs may have application-specific side effects; read their source before running them against real data.

Build the documentation controls example:

```sh
mkdir -p build
c++ docs/examples/controls.cpp -I. -std=c++17 -o build/docs-controls $(pkg-config --cflags --libs cairo x11) -pthread
build/docs-controls --tui
```

## Troubleshooting

| Symptom | Check or correction |
| --- | --- |
| Undefined backend symbols | Define `FT_IMPLEMENTATION` in one linked `.cpp`. |
| Duplicate symbols | Remove implementation defines from other translation units. |
| Missing Cairo/X11 headers or symbols | Install development packages; include both pkg-config compile and link flags. |
| `--tui` has no effect | Pass `argc, argv` to facade creation; direct `ftui::create_window` does not parse these flags. |
| Forced TUI fails | Use interactive stdin/stdout, not pipes; inspect terminal environment. |
| Auto opens web unexpectedly | GUI creation may have failed and no usable TTY was available. Test `--gui` to isolate failure. |
| GUI fails under Wayland | The native backend still needs an accessible X11/XWayland display. |
| Web cannot bind | Check address and port; change `web_port` if another process owns it. |
| Browser data looks stale | Enable positive `web_client_poll_ms` or reload; local redraw does not push HTTP updates. |
| Editing resets every frame | Move buffers/value initialization outside the loop. |
| Wrong control gets input | Use distinct stable labels and consistent form order. |
| Table selection points at a different record | Reconcile source indices after modifying the row collection. |
| Terminal layout is huge | Explicit dimensions are forwarded as cells/rows; use smaller values or proportional layout. |
| Browser clipboard fails | Use localhost/HTTPS and allow access; select/copy manually when unavailable. |
| Linux copied text disappears | The X11 owner must remain alive and process events. |
| `load_image()` is non-null but nothing appears | Check native decoder support and handle contents; web image rendering is a no-op. |
| A tooltip/drawer differs in web | Consult the documented fallback matrix. |

## Performance practices

Load and release images outside the frame loop. Keep UI work short; do not synchronously fetch remote data for every widget render. Reuse application state and avoid rebuilding large strings or datasets when they have not changed. Large tables still calculate ordering over the data; visible rows are not a guarantee of full data virtualization. Select web polling intervals deliberately, and measure with your application's dataset before changing pacing or disabling effects.

## Existing regression checks

Run from the repository root:

```sh
mkdir -p build
c++ tests/data_widgets.cpp -std=c++17 -o build/data_widgets_test $(pkg-config --cflags --libs cairo x11) -pthread
build/data_widgets_test
node tests/context_menu_web.js
c++ examples/ft_combined_smoke.cpp -std=c++17 -o build/ft_combined_smoke $(pkg-config --cflags --libs cairo x11) -pthread
build/ft_combined_smoke --self-test
```

The JavaScript check consumes the fixture generated by the C++ data-widget test, so keep that order. These checks do not replace interactive verification of OS clipboard ownership, terminal capabilities, native dialogs, compositor effects, or browser permissions.

## Polish regression checks

```sh
c++ tests/polish_regressions.cpp -std=c++17 -o build/polish-regressions $(pkg-config --cflags --libs cairo x11) -pthread
build/polish-regressions --sockets
node tests/toasts_web.js
c++ tests/dither.cpp -std=c++17 -O2 -o build/dither-test $(pkg-config --cflags --libs cairo x11) -pthread
build/dither-test
```

The socket tests use local Unix socket pairs on Linux; no remote server is needed. The C++ test writes the fixture used by the toast script check. `tests/polish_benchmark.cpp` measures table rendering and cold/cached dither setup; timing is informational and depends on the machine.
